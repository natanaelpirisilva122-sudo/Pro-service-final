PROSERVICE — VERSÃO DESKTOP PROFISSIONAL

Esta versão mantém a integração React + Node/Express + MySQL e acrescenta:
- Layout desktop com menu lateral.
- Busca profissional dedicada.
- Perfil do prestador redesenhado.
- Chat Cliente x Prestador com histórico no MySQL.
- Lista de conversas e mensagens não lidas.
- Meus Serviços, avaliações e conta integrados ao mesmo padrão visual.

CHAT — BANCO DE DADOS
Se as tabelas conversas e mensagens ainda não existirem, execute backend/database/chat.sql no banco db_ProService.

EXECUÇÃO
1. backend: npm install && npm run dev
2. frontend: npm install && npm run dev
3. abra http://localhost:5173

SEGURANÇA
O arquivo .env não acompanha o ZIP. Copie o .env da sua versão local anterior para backend/.env.
