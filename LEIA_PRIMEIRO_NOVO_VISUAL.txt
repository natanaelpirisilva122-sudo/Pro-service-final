PRO SERVICE — NOVO VISUAL INTERNO 2026

Esta versão mantém backend, banco, autenticação, rotas e regras de negócio do projeto anterior.
O frontend recebeu uma camada visual profissional e responsiva nas telas internas:
- Home do cliente
- Painel do prestador
- Busca/listagem de profissionais
- Serviços e oportunidades
- Perfil do profissional e solicitação
- Conta e edição do prestador
- Login e cadastro
- Navegação inferior

Execução:
1. Backend: cd backend && npm install && npm run dev
2. Frontend (outro terminal): cd frontend && npm install && npm run dev
3. Abra http://localhost:5173

Use o mesmo .env/MySQL configurado no seu computador.
